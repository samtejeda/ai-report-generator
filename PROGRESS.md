### Findings

- Finding (Claude, 2026-10-13): auth provider comparison. Sources: Neon docs (`neon.com/docs/auth/overview`, `neon.com/docs/security/hipaa`) and Better Auth docs (`better-auth.com/docs/...`: reference/options, reference/security, concepts/session-management, concepts/rate-limit, concepts/database, concepts/email), fetched with curl on 2026-10-13; npm registry via `npm view`. Docs are a moving target; re-check before Phase C.
  - **Managed Better Auth (Neon Auth): excluded.** Neon's HIPAA page lists it under "Non-HIPAA-compliant features" ("Uses an authentication provider that is not covered under Neon's HIPAA compliance"). It also does not support projects with IP Allow or Private Networking, and is AWS-only. `@neondatabase/auth` is `0.6.0-beta`. Not usable once real client data flows, and moving off it later would be a migration.
